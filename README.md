# Novatrend Brasil

Projeto de site estático para GitHub Pages.

## Como publicar
1. Faça upload dos arquivos para a raiz do repositório.
2. Garanta que exista `index.html`.
3. Ative GitHub Pages em **Settings → Pages**.
4. Selecione a branch `main` e a pasta `/ (root)`.
